そして、文法チェックを通しても事故は防げません

W3CのNu Html Checkerは、HTMLを貼り付けて文法を検査できます。無料です。 ただし見ているのは「HTMLの仕様に合っているか」だけです。だから、こういうものは全部通過します。

  • 画像のURLが localhost のまま残っている
    → 自分のPCでは最後まで正常に見えます。本番だけ画像が出ません
  • 本文に「サンプルテキスト」が残っている
    → 読み慣れた文字列は、自分の目が飛ばします

    → 環境によって別の文字や □ になります
  • img に width と height が無い
    → 読み込み中に、下の文章が飛びます
  • https のページで、画像だけ http:// から読んでいる
    → ブラウザが遮断します。画像が消え、アドレスバーの鍵マークが外れます

使い方

  1. サイトのフォルダを、この画面にドラッグする（または「フォルダを選ぶ」）
  2. 中の .html が一覧で出るので、見たいファイルを選ぶ
  3. 出た項目を、件数の多い種類から直す

HTMLを直接貼ることもできます（「HTMLを直接貼る」を開いてください）。

ファイルはこのブラウザの中だけで読みます。どこにも送信しません。 ブラウザの仕組み上、あなたが選んだファイル以外は読めません。

よくある質問

貼ったHTMLは送信されますか
されません。全部ブラウザの中で処理します。localStorage にも保存しません。 他人の未公開の制作物を貼ることがあるためです。
文法チェックはしないのですか
しません。W3CのNu Html Checkerが無料でやっています。 結果欄の下からリンクしているので、続けて使ってください。
URLを入れて検査できますか
できません。ブラウザから他のサイトを読むことは、ブラウザ自身の制限（CORS）で禁止されています。HTMLを貼ってください。
リンク切れは分かりますか
分かりません。実際にアクセスしないと404かどうか判定できず、それはブラウザからはできません。 空リンク（href="#"）だけは検出します。
自動で直してくれますか
直しません。何が変わったか分からなくなるためです。場所と理由だけを出します。
画像のファイルサイズは分かりますか
分かりません。HTMLソースには画像の本体が入っていないためです。 画像の書き出しは imgset を使ってください。
複数のファイルをまとめて検査できますか
今の版では1ファイルずつです。

できないこと・間違えること

  • B1：CSSの aspect-ratio で高さを確保している場合も検出します。HTMLソースだけではCSSを見られません。
  • B2：どこがファーストビューかは推測です。最初の2枚までを「最初に見える画像」と仮定しています。
  • C1：<label> で囲む形と for による対応は、どちらも検出しません。ただし aria-labelledby が存在しないidを指している場合は見抜けないため、「疑い」に置いています。
  • D2：120字という基準は目安で、一次情報で確認したものではありません。
  • A2・A4の「疑い」：「サンプル」「仮」「確認」は普通の日本語なので、正規の本文でも出ます。
